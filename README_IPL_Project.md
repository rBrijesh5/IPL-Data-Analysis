# IPL 2023 Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the IPL 2023
dataset using Python, Pandas, NumPy, Matplotlib, and Seaborn.

## Dataset

-   each_match_records.csv
-   each_ball_records.csv

Source: Kaggle IPL 2023 Dataset

## Technologies Used

-   Python
-   NumPy
-   Pandas
-   Matplotlib
-   Seaborn
-   Jupyter Notebook

## Analysis Performed

1.  Most Successful Team
2.  Toss Winner Analysis
3.  Most Player of the Match Awards
4.  Top Run Scorers
5.  Runs vs Balls Comparison
6.  Most Sixes
7.  Most Fours
8.  Best Strike Rate (Minimum 300 Balls Played)
9.  Top Wicket Takers
10. Best Economy Rate
11. Venue Analysis

## Key Insights

-   Identified the most successful team based on total wins.
-   Measured toss impact on match results.
-   Found leading run scorers and power hitters.
-   Calculated strike rates for qualified batters.
-   Identified top wicket-taking bowlers.
-   Compared economy rates of bowlers.
-   Analyzed venue-wise match distribution.
